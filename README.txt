BOLLA EMPLOYEE PROFILE CARD — CORRECTED POPUP FORM
1. Extract the ZIP to a folder.
2. Open index.html in Chrome or Microsoft Edge.
3. Six sample cards appear by default.
4. Click Add Employee Card to open the popup form.
5. Required fields: Full Name, Emp ID, Store Name, Phone, Member. Email is optional.
6. Year Joined automatically uses the current year.
7. Upload Picture accepts JPG, PNG or WEBP up to 4 MB.
8. Click a profile and enter password 2695 to view its details.
9. New cards and pictures are kept in browser memory only and disappear on refresh. Database persistence is not included.
10. Demo only: client-side password is not secure authentication.


11. Employee ID is blurred/masked on all cards.
12. After clicking View profile and entering password 2695, only that selected card changes to navy blue.
13. Added employee cards and pictures are saved in this browser using localStorage and should remain after refresh in the same browser profile.
14. This is browser-local storage, not a shared online database. Data may not appear on another device/browser and may be removed if browser site data is cleared. Very large photos can exceed browser storage limits.
15. Password protection is demo-only client-side logic, not secure authentication for real employee data.

16. The final profile popup uses a modern navy/blue background with brighter high-contrast text and detail cards. It appears after the correct profile password is entered.

17. Final profile popup includes a scannable QR code on the right side of the employee photo/details. It opens https://www.bollamarket.com/ when clicked and scans to that website on mobile.

18. To edit a profile, open View profile, enter password 2695, click Edit Employee, change the fields, then click Save Changes. Updates are saved in this browser's localStorage.

19. Removed the SCAN WEBSITE label. The QR image now gently enlarges when the cursor hovers over it (and on keyboard focus).

20. The employee photo/avatar in the final profile popup now gently enlarges, lifts, and glows when hovered with a mouse.

21. Employee photo/avatar and QR tile now use matching dimensions, rounded corners, border, and shadow for a balanced profile header; both remain hover animated.

22. Employee cards are displayed in ascending alphabetical order by employee name.
23. Duplicate employee names and duplicate employee IDs are blocked when adding or editing a profile (case-insensitive).
24. To delete a profile, open View profile, enter password 2695, click Delete Employee, and confirm. The deletion is saved to this browser's localStorage.

Joined Date update: employee cards display Joined dates in MM/DD/YYYY format (for example, 10/25/2026). The Add/Edit Employee form uses a date picker. Older year-only records are displayed as 01/01/YYYY because the original day and month were not saved; edit the employee to select the correct date.
