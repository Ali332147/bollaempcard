BOLLA EMPLOYEE PROFILE CARD — NAVY BLUE + SAVE AFTER REFRESH
1. Extract the ZIP into a folder.
2. Open index.html in Chrome or Microsoft Edge.
3. Six sample cards are shown by default.
4. Click Add Employee Card, fill in the popup, and submit. The new profile is saved in browser localStorage and should remain after refresh/reopening the page in the same browser profile.
5. Navy-blue card styling has been strengthened.
6. Password for viewing profile details: 2695.
7. Picture upload supports JPG, PNG and WEBP up to 4 MB.
IMPORTANT LIMITATIONS:
- This version saves profiles only in the same browser profile on this computer. It does not sync to another device or browser.
- Browser storage can be cleared by browser settings, and opening the file in different browser contexts may not share saved data. For more reliable use, host the app and connect a database/backend.
- Uploaded photos are stored as data URLs in browser localStorage. Large photos or many profiles may reach the browser's storage limit; use small images.
- Client-side password is demo-only, not secure authentication.
